# ECBD---Estrella
Repositorio de practica de materia Extracción de Conocimiento

Nombre del alumno:Rosy Estrella Morales Soto

Materia:Extracción del conocimiento de Base de Datos

Cuatrimestre: 9° B 

Descripcion general: Este repositorio contiene las prácticas de laboratorio 
desarrolladas durante el primer parcial de la materia. Cada notebook aplica técnica 
de análisis de datos reales, desde la limpieza y exploración hasta la visualización e 
interpretación de resultados.

 Objetivo:
Limpieza y preprocesamiento de datos
Análisis descriptivo y estadístico
Visualización de datos con gráficas legibles
Interpretación y generación de conocimiento

Herramientas Utilizadas:
Python Lenguaje principal
Jupyter Notebook / Google Colab Entorno de desarrollo
PandasManipulación y análisis de datos
Matplotlib Visualización de datos
Seaborn Gráficas estadísticas
NumPy Operaciones numéricas
GitHub Control de versiones y documentación

Conclusiones Generales:
A lo largo de este primer parcial se trabajó con datasets reales aplicando el proceso 
completo de extracción de conocimiento:
Datos:Se recopilaron y cargaron datasets públicos como el catálogo de Netflix, 
identificando su estructura y tipos de variables.
Información: Mediante limpieza y análisis descriptivo se identificaron patrones, 
valores nulos y estadísticas relevantes.
Conocimiento:A través de visualizaciones se generaron hallazgos significativos sobre 
los datos, como tendencias en géneros, países de producción y distribución temporal.
Sabiduría:Se establecieron criterios para la toma de decisiones basadas en los datos 
analizados, aplicando buenas prácticas de documentación y reproducibilidad.
Este proceso refuerza la importancia de mantener un repositorio organizado, con 
documentación clara y análisis bien fundamentados.
